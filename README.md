# POSTGRESQL PACKAGES

This repository maintanis non-official add-on packages for PostgreSQL

## Contributing

We welcome contributions from the community. Before submitting a pull request, please review our [contribution guide](./CONTRIBUTING.md).

## Getting started

Modules for version 8.4.x of PostgreSQL are under the `postgre_v8.4.x` folder. Extensions for newer versions (v10+) are under the `postgres/<version>` folder.

Each module/extension has its own **README.md** file; please follow the instructions provided there.
